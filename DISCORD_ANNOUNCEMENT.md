***REMOVED******REMOVED******REMOVED*** Track Setups — Setups für jede Strecke
> Wer kennt's: Neue Strecke, 0 Idee wo man mit dem Setup anfangen soll. Vorbei.

Wir haben eine **komplette Setup-Library** gebaut. Für jede F1 26 Strecke hinterlegen wir Setups, die ihr direkt ins Spiel übernehmen könnt. Filtern nach Strecke, durchklicken, fertig.

**Was ihr seht:**
- Komplette Setup-Werte (Aero, Aufhängung, Differential, Bremsen, Reifendruck)
- Reifen-Empfehlung (Soft/Medium/Hard/Inter/Wet)
- Rennstrategie inkl. Boxenstopp-Plan
- Kommentare & Likes von der Community
- Tutorial-Video von <OWNER_HANDLE> direkt eingebettet — falls jemand noch nie ein Setup importiert hat

**Zugriff funktioniert in Stufen:**
- 🌐 **Öffentlich** — basic Setups, jeder sieht sie
- 💬 **Community** — auf dem Discord? Dann hast du Zugriff auf mehr Setups
- 🟣 **Twitch-Sub Tiers** — Pit Crew / Race Engineer / Team Principal Setups gibt's für Subscriber von **twitch.tv/erdi10**

So verknüpft ihr euren Twitch-Sub mit Discord:
1. Discord öffnen → Einstellungen (Zahnrad)
2. **Verknüpfungen** → **Twitch** anklicken
3. Mit Twitch anmelden, autorisieren — fertig

Sobald das durch ist, schaltet die Seite automatisch die Setups frei, auf die ihr Anspruch habt.

➜ **Setups öffnen:** `F1 Setups` in der Navigation
